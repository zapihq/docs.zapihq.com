Zapi is a payments API for Ethiopian merchants. You send one request, the payer
confirms, and the payment settles to your balance.

The API reference grows as each endpoint is specified. Until then, the samples
on this site are illustrative: they show the shape of a request and response, not
a frozen contract.

## Start here

- [Quickstart](/docs/quickstart) — send a payment in test mode.
- [API reference](/docs/api-reference) — requests, fields, and responses.
- [Payment methods](/docs/payment-methods) — telebirr, bank accounts, and cards.
- [Webhooks](/docs/webhooks) — receive `payment.success`.
- [Test mode](/docs/test-mode) — simulate payments without moving money.
