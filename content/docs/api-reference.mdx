## Create a payment

`POST /v1/payments` creates one payment and returns it with a checkout URL.

| Field       | Type    | Notes                                           |
| ----------- | ------- | ----------------------------------------------- |
| `amount`    | integer | Minor units (santim). `100000` is 1,000.00 ETB. |
| `currency`  | string  | ISO 4217 code, uppercase.                       |
| `provider`  | string  | `telebirr`, `cbe`, `awash`, or `card`.          |
| `reference` | string  | Your own identifier for the sale.               |

```json
{
  "id": "pay_9f2c1a",
  "status": "initiated",
  "amount": 100000,
  "currency": "ETB",
  "provider": "telebirr",
  "checkout_url": "https://pay.zapihq.com/pay_9f2c1a"
}
```

## Identifiers

Every object carries a typed prefix: `pay_` for payments, `refnd_` for refunds,
`acct_` for virtual accounts, `req_` for idempotency keys, and `whsec_` for
webhook secrets.
