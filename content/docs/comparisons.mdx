Zapi, Chapa, Santimpay, and Arifpay are payment gateways: each fronts several
providers behind one API, so a merchant integrates once. A provider is the
institution behind a payment method — a bank, or a wallet provider such as
telebirr — and is not a payment gateway. This page compares gateways, not
providers.

Competitor facts come from each gateway's own public material. Every row records
when it was checked; a cell that reads `not published` means that material does
not state the fact, not that the capability is absent. The Zapi column comes
from this documentation and the OpenAPI contract in this repository.

## What the table does not cover

The rows describe capabilities that each gateway publishes, not commercial
terms or performance. Fees and rates change, so the pricing row links to each
gateway's own published pricing page instead of copying a number.

The Zapi column lists what this repository's contract supports today; each
competitor cell repeats only what that gateway's own material states. For the
request shapes behind the Zapi column, start with the
[Quickstart](/docs/quickstart) or read [Concepts](/docs/concepts).
