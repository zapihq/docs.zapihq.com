The reference documents every endpoint, field, and response for payments and
payouts. Amounts are integer santim, currency is uppercase `ETB`, and every
`POST` requires an `Idempotency-Key`.

The pages are generated from `content/openapi/*.yaml`; the contract is the source
of truth, not the prose.
