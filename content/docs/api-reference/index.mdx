The reference documents every endpoint, field, and response for payments and
payouts. It is generated from `content/openapi/payments.yaml` and
`content/openapi/payouts.yaml`; those files are the contract, and the pages
change when the specs change.

The base URL is `https://api.zapihq.com/v1`. Amounts are integer santim, currency
is uppercase `ETB`, and every `POST` requires an `Idempotency-Key`.

## Conventions

- Paths are versioned in the URL: `/v1/payments`, `/v1/payouts`.
- JSON fields are snake_case. Multi-word path segments are kebab-case.
- Timestamps are ISO 8601 UTC.
- Identifiers carry typed prefixes: `pay_`, `refnd_`, `po_`, `rcp_`, `whe_`,
  `evt_`, `req_`, `whsec_`.
- `GET` requests do not take an idempotency key. `POST` requests always do.
- The API returns `200` for a successful write, not `201`.

## Versioning

The docs are single-version; the API version lives in the `/v1` path. When a
future version ships, it gets its own path rather than a docs selector. Changes
that affect the contract land on the [changelog](/changelog).
