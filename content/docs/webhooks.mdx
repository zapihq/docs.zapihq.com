---
title: Webhooks
description: Receive payment events at your endpoint.
---

Register a webhook endpoint in your Zapi account, then acknowledge each delivery
with a `200` response.

## The payment.success event

`payment.success` is sent when a payment completes. The payload below is
illustrative; the full event lexicon is not published yet.

```json
{
  "type": "payment.success",
  "data": {
    "id": "pay_9f2c1a",
    "amount": 100000,
    "currency": "ETB",
    "provider": "telebirr"
  }
}
```

## Handling a delivery

Read the event, find the payment by its `pay_` identifier, and return `200`
before doing slow work. Delivery is at-least-once: handle the same event twice
without charging or crediting twice.

## Signature verification

Deliveries carry a `zapi-signature` header. The verification scheme is planned
and will be documented here before it is required.
