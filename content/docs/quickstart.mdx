This guide sends one payment in test mode and reads the response. No real money
moves.

## 1. Use a test key

Test-mode requests carry a secret key that starts with `sk_test_`. Send it in the
`Authorization` header as a bearer token.

## 2. Create a payment

`POST /v1/payments` takes an amount in santim, a currency, and the provider the
payer will use. The sample below is illustrative: `amount: 100000` is 1,000.00
ETB.

```bash
curl https://api.zapihq.com/v1/payments \
  -H "Authorization: Bearer sk_test_..." \
  -H "Idempotency-Key: req_9x8h2m" \
  -d amount=100000 \
  -d currency=ETB \
  -d provider=telebirr \
  -d reference=order_1042
```

## 3. Read the response

The response returns a typed payment identifier and a checkout URL. Send the
payer to that URL to approve the payment.

```json
{
  "id": "pay_9f2c1a",
  "status": "initiated",
  "amount": 100000,
  "currency": "ETB",
  "provider": "telebirr",
  "checkout_url": "https://pay.zapihq.com/pay_9f2c1a"
}
```

## 4. Wait for the event

When the payment succeeds, Zapi sends `payment.success` to your webhook
endpoint. [Webhooks](/docs/webhooks) covers what to do with it.
